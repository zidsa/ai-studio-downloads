# Zid AI Studio Downloads

Download the [Zid AI Studio 0.1.0 beta](https://github.com/zidsa/ai-studio-downloads/releases/tag/v0.1.0) for Mac with Apple Silicon.

1. Open **Apple menu → About This Mac** and check that the chip is Apple M series.
2. Download and open the Apple Silicon DMG.
3. Drag **Zid AI Studio** to **Applications**, then open it from there.

Intel Mac and Windows installers are pending.
